# ConstructRegis — общий реестр работ

Вход: https://dexvetr.github.io/constructregis/

Общий проект: https://route-fact-pilot.dexvetr.chatgpt.site/shared

Задания и объёмы хранятся в серверной базе и видны всем участникам по ссылке. Вход не требуется. Открытая страница обновляет данные каждые 3 секунды. Все демонстрационные роли доступны каждому участнику. Массовое удаление общих записей отключено.

GitHub Pages служит входной страницей и перенаправляет в серверное приложение. Старый source.zip содержит исходники предыдущего автономного демо с локальным хранением, а не текущей серверной версии.
