# Маршрут по факту — демо

Открыть: https://dexvetr.github.io/route-fact-demo/

Задания бригадам → ввод объёмов → проверка инженером → журнал КС-6а и экспорт Excel.

Каждый посетитель работает с учебными данными в своём браузере. Вход не требуется. Изменения сохраняются в localStorage и не видны другим посетителям. Очистка браузера удаляет записи.

index.html — автономная сборка приложения. source.zip — исходники React/TypeScript, тесты и конфигурация сборки. Для разработки распакуйте архив и следуйте README внутри.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
